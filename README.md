PWBL Website – Full-Stack Django Redevelopment

A complete redevelopment of the PWBL website, migrating its previous PHP-based implementation to a modern Python Django web application.

Project Overview

This project involved independently redeveloping the existing PWBL website using Python and Django. The objective was to migrate the previous PHP-based website to a Django-based architecture while maintaining its website functionality and improving its overall structure.

The entire project, including frontend development, backend implementation, database integration and admin panel development, was completed independently.

Running Locally

1. Clone the repository:

git clone https://github.com/Priyansh-swami/pwbl-website.git

2. Navigate to the project directory:

cd pwbl-website

3. Create a virtual environment:

python -m venv venv

4. Activate the virtual environment:

venv\Scripts\activate

5. Install dependencies:

pip install -r requirements.txt

6. Apply database migrations:

python manage.py migrate

7. Start the development server:

python manage.py runserver

8. Open the local development address:

http://127.0.0.1:8000/
